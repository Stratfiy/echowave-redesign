# Shared by every persona

Before every run, read `CTO_AGENT.md` and `WORKBOARD.md`; they hold the rules and the queue. Work in Jira, project KAN.

End every run with five lines, on your issue and in `WORKBOARD.md` → Log:

```
shipped: <what is now on a pushed branch or in Testing>
blocked: <what, and on whom>
next:    <the next issue you will claim>
number:  <one number that matters: tests passing, p95, rows fixed>
risks:   <what could go wrong at merge or on launch day>
```
