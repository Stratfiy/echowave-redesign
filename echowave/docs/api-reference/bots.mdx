An agent is a job the business has hired an agent for: answer the phone, confirm orders, chase payments. Create one from a template or a definition, update its draft, publish, and read its versions.

| Method | Route | What it does |
|---|---|---|
| [`bots.createFromTemplate`](/api-reference/bots/create-from-template) | `POST /api/v1/workflows/create/template` | Describe the agent in plain words and get a working draft. |
| [`bots.create`](/api-reference/bots/create) | `POST /api/v1/workflows/create/definition` | Create an agent from a full definition. |
| [`bots.list`](/api-reference/bots/list) | `GET /api/v1/workflows/fetch` | Every agent in the account. |
| [`bots.summary`](/api-reference/bots/summary) | `GET /api/v1/workflows/summary` | Ids and names only, for pickers. |
| [`bots.count`](/api-reference/bots/count) | `GET /api/v1/workflows/count` | How many agents the account has. |
| [`bots.get`](/api-reference/bots/get) | `GET /api/v1/workflows/fetch/{workflow_id}` | One agent: its draft if it has one, else what is live. |
| [`bots.update`](/api-reference/bots/update) | `PUT /api/v1/workflows/{workflow_id}` | Save the draft. |
| [`bots.validate`](/api-reference/bots/validate) | `POST /api/v1/workflows/{workflow_id}/validate` | Check a definition before publishing. |
| [`bots.publish`](/api-reference/bots/publish) | `POST /api/v1/workflows/{workflow_id}/publish` | Make the draft the live version. |
| [`bots.createDraft`](/api-reference/bots/create-draft) | `POST /api/v1/workflows/{workflow_id}/create-draft` | Start a draft from what is live. |
| [`bots.versions`](/api-reference/bots/versions) | `GET /api/v1/workflows/{workflow_id}/versions` | Every version, newest first. |
| [`bots.restoreVersion`](/api-reference/bots/restore-version) | `POST /api/v1/workflows/{workflow_id}/versions/{version_id}/restore` | Copy an older version into the draft. |
| [`bots.setLive`](/api-reference/bots/set-live) | `PUT /api/v1/workflows/{workflow_id}/live` | Turn an agent on or off for calls. |
| [`bots.setStatus`](/api-reference/bots/set-status) | `PUT /api/v1/workflows/{workflow_id}/status` | Archive or restore an agent. |
| [`bots.duplicate`](/api-reference/bots/duplicate) | `POST /api/v1/workflows/{workflow_id}/duplicate` | Copy an agent. |
| [`bots.callOutcomes`](/api-reference/bots/call-outcomes) | `GET /api/v1/workflows/call-outcomes` | Every outcome label the account's calls can carry. |
