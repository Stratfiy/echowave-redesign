Tax documents, receipts, credit notes and payment history. There is no checkout: plans, top-ups and auto top-up are gone, and their routes answer 410.

| Method | Route | What it does |
|---|---|---|
| [`billing.balance`](/api-reference/billing/balance) | `GET /api/v1/billing/balance` | Credit balance. |
| [`billing.payments`](/api-reference/billing/payments) | `GET /api/v1/billing/payments` | Every payment. |
| [`billing.documents.list`](/api-reference/billing/documents-list) | `GET /api/v1/billing/documents` | Receipts, tax invoices and credit notes. |
| [`billing.documents.get`](/api-reference/billing/documents-get) | `GET /api/v1/billing/documents/{document_id}` | One document. |
| [`billing.documents.pdf`](/api-reference/billing/documents-pdf) | `GET /api/v1/billing/documents/{document_id}/pdf` | The document as PDF. |
