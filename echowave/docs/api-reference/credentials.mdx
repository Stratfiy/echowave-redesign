Keys and passwords a bot's tools use, stored once and referenced by id. A bot never sees the value.

| Method | Route | What it does |
|---|---|---|
| [`credentials.create`](/api-reference/credentials/create) | `POST /api/v1/credentials/` | Store a credential. |
| [`credentials.list`](/api-reference/credentials/list) | `GET /api/v1/credentials/` | Every credential, by name and hint. |
| [`credentials.get`](/api-reference/credentials/get) | `GET /api/v1/credentials/{credential_uuid}` | One credential's metadata. |
| [`credentials.update`](/api-reference/credentials/update) | `PUT /api/v1/credentials/{credential_uuid}` | Replace the value. |
| [`credentials.delete`](/api-reference/credentials/delete) | `DELETE /api/v1/credentials/{credential_uuid}` | Remove a credential. |
