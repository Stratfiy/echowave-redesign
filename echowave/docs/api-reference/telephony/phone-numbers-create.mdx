Add a number and point it at a bot.

{/* generated: prose below this line is kept */}

Set `inbound_workflow_id` to bind incoming calls on this number to a specific agent — Decibyl will register the inbound webhook with the provider and the response will include a `provider_sync` block reporting the result. Omit it to add the number for outbound use only.

The `(provider, account_id, address)` tuple must be globally unique across all Decibyl organizations, since inbound dispatch keys on it. Attempting to add a number that another organization already owns returns `409`.
